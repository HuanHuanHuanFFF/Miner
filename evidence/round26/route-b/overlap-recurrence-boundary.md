# A inherited-overlap implementation boundary

Current scope: B12 observes the original #552 trajectory only. No new edge, production candidate, quality result or performance result has been produced.

INFERRED local validity argument: assume every cached record supplies a byte-valid `(length,distance)`. At the end of an original position, either `XL/XD` is the maximum-length cached record (the empty-record case has `XD=0` and cannot qualify), or it is the old inherited pair extended by one byte. At the predecessor, the old prefix remains valid at its shifted source; checking the new preceding byte suffices for `min(XL+1,258)` bytes. Segment tails can reach beyond `pe`, so this statement depends on input bytes and cache validity, not a truncated segment. B12 tests actual complete prefixes with original `check` rather than assuming this argument has been proved.

VERIFIED finite model: [overlap-invariant-model.json](overlap-invariant-model.json) checks 16,380 trajectories, including arbitrary record subsets, reverse record order, segment tails and lengths around 258. It also preserves a concrete invalid mixed pair: at input position 16 the valid longest pair is `(5,5)` and another valid pair is `(3,6)`; carrying old length 5 with new distance 6 to position 15 produces invalid `(6,6)`. These finite checks do not establish original Rust or Lean obligations.

Consequent implementation boundary: original `XL/XD` remains independent of any newly winning `best/bd`. Updating only the inherited distance is unsound; replacing both by a new shorter winner also changes later offered edges, so it does not preserve the authorized original recurrence. Any new selection should update only the planned cost/choice after all original offers have been evaluated, retaining the old cache, record boundaries and original extension state.

Original normal records offer their new length interval; fixed-only records offer one endpoint. An inherited candidate may replace an expensive distance on an existing interval, or offer a fixed-only prefix that did not exist. These are separate mechanisms. Normal record intersections must be calculated using `prev` before the record advances it. The original uncovered extension is excluded from the new opportunity count and still runs unchanged.

The packed objective is a wrapping U32 sum shifted by 9 with length as the low tie key. Strictly smaller distance price is a proposed search guard, not a proof that the shifted objective improves or that original encoder output shrinks. B12 evaluates actual wrapped packed values, counts discarded high bits and same-price shorter ties, and compares with the original final `best`. Production selection must preserve those exact comparisons unless a reachable-state arithmetic bound is independently proved. No modeled bit-gap sum may be reported as saved output bytes.
