# R27：新公开源码与第一圈实验预声明

固定预算见 budget.json。目标：最新官方榜单下稳定至少 5% 竞赛池份额；正式上传、注册和签名不在本轮授权内。保留最后 35 分钟作完整 gate、冻结后两台新 runner 确认、最新快照复算和收尾。

新取得公开源码：683、669、673、707、708，原始响应、作者和 Rust/Lean 哈希见 public-start 与 references/round27-public-*。683/669/673 的当前官方累计奖励为正；请求的五个历史 snapshot ID 没有完成记录，保留 404，历史高份额及持续性 UNKNOWN。707/708 当前累计奖励为零，作为不同机制/证明较小的替代起点。没有将它们称为已证实历史高份额实现。

第一圈实质差异：

- A1，从683改 pc_f_try 的首字比较/长度发现，使用现有字级 pc_xlen 入口后继续原公共 scanner；保留短尾回退、边界和可信发射验证。与父版预期同输出；完整正确性仍需新 gate。
- A2，从683改变三个热函数的编译内联边界；控制流与输出保持一致，证明复用仅是草稿。观察真实总时间是否改善，而非只看 parser 汇编。
- B1，从708复用707已公开的首个八字节前缀专用路径，同时保留708的原路由/压缩配置，构成明确组合消融。借用707证明不代表此组合通过验证。

缺口：新增前沿已支配旧起点；原快照30183下各父版池份额均0。必须从原版时间和大小读数决定复测价值。最小操作为13个候选/参照进程的一块原协议11rep完整压缩测试，含父版与候选同源码副本、有限同输出比较。Job硬上限22分钟，预计6–14分钟，排队UNKNOWN。结果路径 evidence/round27/<run>/screen-new1/gate。

决策：有正份额/两轴空间时低成本逐块评分与邻居敏感性重放，再投入完整 gate 和独立新 runner；同源码差异翻转排序时优先保存并诊断，不用峰值晋升。无收益但不同机制有明确后续价值时按剩余预算改进；不机械扫参数。

重要反馈：opportunity-start.json 的全局二分法曾假设份额单调，实际重放发现 X=0.45 比 X=0.42 份额更高，故该文件的阈值不得用作可达性结论。保留旧推断，改用区间扫描与局部边界确认。公共估算仅是条件几何投影，不是正式或私有集成功概率。
