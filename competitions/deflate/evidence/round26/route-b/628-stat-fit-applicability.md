# B10 统计拟合机制对 #628 的静态适用性

结论：#628 的较大 SFbase 成本不能全部当成 B10 可替换的 A 拟合空间。B10 在 #552 真实质量增加 12,213 B／0.039518 pp，停止此精确版本的配对与证明；不再为 #628 同构开第二份变体。

**VERIFIED 静态**：#552 的 a_engine 对应 #628 的 Z185（名称与常量规范化后正文相同），其 matcher/cache/final DP 与 B10 统计来源接口兼容。#628 还包含 Z308、Z144、Z336 等其他基础规划，不能仅因为都属于基础阶段直接替换。

| #628 基础规划 | 适用性与必须保留的差异 |
|---|---|
| Z185 → Z186 / Z184 / Z187 | 同构的 plain A：完整缓存是 mp/mb；成本与长度 tie 对应 #552。可以复用统计机制接口，但未实施、未测质量／速度。 |
| Z308 → Z145 / Z307 / Z309 | 仍有完整缓存，但规划加入 token +2、反向长度 tie、tail/final_tail，Huffman 构价采用无平滑 Z156。任何新统计来源必须保留末轮这些差异；不能简单套 B10 的 plain A final DP 或平滑构价。 |
| Z144 → Z145 / Z143 / Z154 | 含 preset 种子价格、块范围与预算控制；seed/bidx、tail、最终价格更新均属真实输入状态。它不是统一重复多遍 plain A。 |
| Z336 → Z368 / Z414 等 | 缓存和选择表示不同，使用另一段 range-minimum／块价规划，B10 的 mp/mb 位域与外围循环不能直接用。 |
| C、D、其他基础路径 | 不在 B10 A 拟合改动范围；SFbase 的汇总不能算这些路径可省。 |

**VERIFIED 历史路径，非当前新测量**：R24 相同基础家族的 profile-i 原回执 `38083109099` 将 Z185 定位在 bundle、source.c、source.rs、tiny-app 四文件，将 Z308 定位在 catalog、config、docs、lean、prose、source.py 六文件。其函数总计 SFbase 2.1308 s、Z185 0.4521 s、Z308 0.7572 s，均为嵌套诊断时间。#628 与该家族的分类器／SFbase 文本关系见 R25 `public628-handoff.json`；当前实际逐文件 A 阶段仍需绑定 #628 新观察，不能由旧秒数或路径表报新增收益。

当前 B7 将整份 SFbase 映射为约 72.4% 父时间轴的投入模型，只说明基础阶段值得研究。若后续有能追回 B10 质量且保留大幅省工的不同统计机制，再选择一个明确父接口作新 native 检查，不根据这一汇总百分比双开同构候选。

证明接口：#552 旧 Lean 465,766 B，剩 58,522 B，B10 的 helper／A 父循环尚未适配或提取；#628 旧 Lean 523,018 B，仅剩 1,270 B，移植多个父函数前必须有实际接口和容量方案。Rust／Lean 哈希分别保留于冻结 manifest 与原公开来源。父证明、历史相同内核和新 native 解码均不能替代精确完整 gate。
