# Warm-prefix return boundary: codegen decision

`SegmentedHotProbe.lean.inc` SHA `07b7fad00a5c8a6099cedecde9fd4ad649b38639ae7fd99fd8a443a5109b158d` is a new **NOT_RUN** codegen discriminator using actual indexed8 A/cache/USize accesses and the eight unchanged MUL-then-ADD recurrences. It is not a full BMM candidate. Runtime/LLVM/performance outcomes remain UNKNOWN.

The old indexed8 assembly (`40611570030`, source `8e27`, `native-loop-33.asm.txt` SHA `91a88fc3383c72db68d9058e7e008fa131e9d7840ed79e0ab8f50fee388c6c3b`) has four possible decoder calls and common q-vector stack loads/stores. This is already documented in R22 `WARM-A-SCAN-PREMISE.md`; it is not a new observation or controlled causal result. The current assembly index explicitly describes a statement-build object; existing timed-object linkage is recorded separately in `development-prepared-resident8/indexed8-actual-review.json`. No new timed-object claim is added here.

The new discriminator uses a self-recursive warm worker that contains no `convert` or `Float32.ofBits` call. When any of the four raw words fails the exact old `fastOK` test, it returns **before any accumulator update**, carrying k, cursor and eight scalar accumulators in an explicit Exit record. The record and its destruction are charged costs. This differs from R22's same-ABI mutual-tail proposal, which needed successful cross-function tail jumps and no post-call reference counting. It also differs from the prior whole-four-row qualification scan: no preliminary 4n scan is performed.

The first integration policy should use only one warm-prefix attempt per tile, then call the unchanged original wordLoop on the entire remainder from the returned state. This gives at most one extra Exit boundary per tile and removes the need for any cross-recursive driver. Repeated warm/cold segment resumption is a later policy, only if measured segment density justifies its additional records; the initial probe does not implement either driver.

First rejectable check: compile this exact function under the pinned ordinary build, identify its reduced body, and inspect the actual warm backedge. Reject before proof expansion if decoder calls remain there, q still traverses stack on each normal k, or self recursion introduces transition allocations/dynamic calls. An Exit allocation at the return boundary is expected. If that prerequisite passes, implement the one-prefix wrapper with an output-read-bounds certificate and prove prefix preservation against old wordLoop by the identical per-k recurrence. Under each exact `fastOK u = true` fact, `R2W01b.convert u = tableProduct u` is merely unfolding the existing conditional; no new IEEE numerical lemma is required for this transport. Then measure complete caller cost, including warm classification, cold duplicate reads, Exit lifetime, old tail rows, B packing and finish/raw replay.

Opportunity limits: this exact four-row fragment inherits the old dimension guard and cannot by itself exceed the 7.9–8.6% whole-sample time bound in `cost-frontier.json`. The mechanism could later be applied to two-lane/SUM workers, but their ABI, cold density and dominant costs require separate evidence. No >10% whole-package gain is claimed. Historical bounded search of R22 independent-frontier prose/source found warm scans and mutual-tail proposals, but no exact return-record prefix worker; this is a scoped history result, not novelty evidence.

Stop rules: no new public CI in the current short window; do not expand mathematical proof or add speculative dispatch thresholds before the codegen prerequisite. The measured indexed8 public proof chain remains the current integration priority.
