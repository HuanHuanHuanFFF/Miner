# Checked word construction through actual scaled rounding and fallback

`AffineScaledWord128.lean.inc` closes a further proposed runtime path beyond checking an already-built numerator. Its exact generic reference is

`P = signed(A)·G + signed(B)`;

`NativeBinary32.roundRatScaled (P<0) |P| D source`.

A and B arrive as128-bit word pairs, G and D as64-bit words. The fast multiplication branch requires A<2^104 and G<2^24. One `mul64 A.lo G` plus one ordinary `A.hi·G` product constructs the128-bit product, with the published add64 carry check. This is five partial64-bit multiplications in source, rather than eight for two full `mul64` calls. It does not turn a full128×64 product into one CPU instruction. The signed combination either adds with a128-bit carry check or performs ordered subtraction. It computes the exact sign and magnitude, including exact cancellation as a miss.

The result feeds the frozen raw scaled checker with independent source and candidate exponents. On acceptance the function packs the word using the exact sign; the mantissa and exponent may come from **any** guesser. On rejection `roundWithFallback` constructs the wide exact integer P and calls the actual native rational rounder. Its proposed theorem equates that complete operation to the actual reference for all inputs and guesses, including failed width/carry checks, D=0, zero, opposite signs and unhandled output cells. There is no assumed correct fallback argument or abstract hcell predicate. The accepted path avoids constructing P as Nat/Int. Standard field packing still converts the small mantissa/encoded exponent to Nat; those are not wide numerator reconstruction.

This is complete only for the generic affine input operation. A norm caller must still supply exact centered/aligned word A/B and D, generate a proposal, preserve stable/legacy guards and release all row/output state. Those are real work and are not implemented by this helper. At the first-Mixer capacity bounds A<2^70,G<2^24,B<2^86, the product and sum fit below2^95, which matches this fast construction. Other valid final results can be rejected because an intermediate or alignment is too wide; fallback preserves them.

`affine_scaled_model.py` checks10,000 exact constructions/complete results over two discovery seeds, plus three exact-zero/cancellation cases. The bounded A70/G24/B86 groups have5,000 valid word constructions and5,000 accepted **perfect reference proposals**. Full128/gain64 mixed-width groups deliberately exercise guards and fallback. These counts establish neither native guess quality nor workload acceptance probability. Three structural mutants produce explicit wrong nonzero output4b000001 while the reference is7f800000: dropping A's high-width guard, dropping G's24-bit guard, or dropping signed-add carry validation.

It appends the exact frozen ScaledCell/ScaledWord128 bodies and this new component, with19 audit roots. No prior frozen file changes.
