# Numeric UInt64 MUL: first discriminator

Decision: continue the bounded numerical bridge and runtime core. This removes a specific external-call boundary that the R16 c972 selected C retained, unlike the temporal storage proposal. It is not a reset of c972's full-gate negative whole1.03055/MUL1.08190 result. Runtime speed, new compiler lowering and profitability remain UNKNOWN.

For mantissas a,b in[2^23,2^24-1], N=a*b lies in[2^46,2^48-2^25+1]. Let h=floor(log2 N),t=h-23 and R=RNE(N/2^t)*2^t. The positive Float32 native product has exactly the integer value R. h is46 or47; rounding can carry46→47, but cannot reach48 because at h47 its quotient is at most2^24-2 before the rounding increment, and the exact maximal endpoint rounds to2^48-2^25. Hence2^46<=R<2^48<2^64. The reverse cast truncates an already integral nonnegative value and neither saturates nor changes it.

Set b=[R>=2^47], q=R>>(23+b). Then q is the normalized24-bit significand, in[2^23,2^24), and R=q*2^(23+b). For raw exponents exu,exv, the source operands are a*2^(exu-150),b*2^(exv-150). The output field is therefore **E=exu+exv-127+b**, fraction q-2^23, sign XOR. With unchanged normal-input and128<=exu+exv<=380 guards, E is1..254; no target subnormal/overflow bridge is needed. b must be tested on rounded R, not exact N: (2^23+1)*(2^24-2)=2^47-2 rounds upward to2^47.
