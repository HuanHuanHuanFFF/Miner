# Deferred interface check while exact c70c first discovery runs

No new source, predicate, plan or proof claim. This note is actionable only if the real first-discovery evidence supports combining temporal packing with D's USize work; two speculative savings are not additive evidence.

One genuine proof-interface trap must be addressed before such a combination: the current accepted `loop_eq` quantifies arbitrary t and computes `k=4*t` before its tests. A machine t may be at least USize.size/4 even when `n<USize.size`; multiplying it by 4 can wrap. For example n=2 and t=USize.size/4 gives Nat k=USize.size (immediate termination) but machine k=0 (would enter a partial block). A direct textual Nat→USize rewrite cannot preserve this arbitrary-t helper statement using only `n<USize.size`.

A viable all-input interface is to test `t<ceil(n/4)` before calculating `4*t`. For a live block this implies `4*t<n`; with n<size the multiplication is exact. Every emitted j must satisfy j<min(4,n−4*t), which proves both `4*t+j<n` and A's existing row-bound condition. At terminal t, return the current accumulators without constructing k. Alternatively carry the appropriate reachable-state invariant into a word helper. The original zero-entry public execution is not thereby shown incorrect: it recurses only after a full four-item block, and short tails return directly. For a live aligned k, `k+3` also fits because USize.size is divisible by 4. Huge array/dimension cases retain a Nat fallback at the public entry, as D's indexed baseline does.

The required formal bridges are ordinary Nat/word/address equalities; the accepted c70c `loop_eq`, existing Packed10Index step/add lemmas and original raw finish can remain the semantic target. Exact wrapper/caller C must still show the machine guards are hoisted per matrix/row rather than recreated per MAC. The verified current C's four decoder calls and the complete cost of preparation/output do not disappear from indexing alone.

Terminal-output fusion is a different optional combination: it can transport the already accepted two-accumulator result into original finish/push and remove only the terminal result record/lane fold. The extra live A/B/output arguments remain a real cost. Neither combination is started or queued until parent/D evaluates the existing independent sources' complete first-discovery data.
