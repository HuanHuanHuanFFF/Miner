# Borrow propagation: final source prerequisite

The one 1400-byte probe remains exactly 680ca1b3. This audit adds no runtime version, Kernel, CI or numerical sample. All primary sources below are the pinned Lean commit 293d5d0c0c3f3dded4688b3ccd6a33939ac5102b; borrowed-interface-audit.json binds their bytes and Git blob IDs. Existing tail-compiler-source-verification.json binds the reused WF, predefinition, InferBorrow and EmitC sources. Default-branch search was used only to locate paths, not as evidence of pinned behavior.

The annotation has a source-supported path into the native compiler. Types.lean:204–213 remembers a borrowed forall binder while lowering its type. ToLCNF.lean:394–404 marks the parameter borrowed when either the lambda type or corresponding function-type binder has the marker. ToDecl.lean:175–179 only clears annotations under compiler.ignoreBorrowAnnotation; Options.lean:38–42 defaults that option to false. The probe does not set it and does not add an export attribute. This is stronger than assuming the surface @& syntax survives automatically, but it still does not replace emitted-C inspection.

The original parameter types survive the WF code path: tail-WF-Main.lean:81–83 compiles the original predefinitions; tail-PreDefinition-Basic.lean:262–266 uses their original types and values. Its default modifier reset at 294 does not alone establish loss of the original noinline hint: ToDecl.lean:130–135 normalizes the internal recursive name back to the original declaration before reading its inline attribute, while getDeclInfo? at 105–107 selects the recursive implementation. Thus there is no source reason here to invent a second probe or add an unsafe wrapper.

Array.getD is inline at Prelude.lean:3307–3308; its size and indexed-read primitives take the array borrowed (3269 and 3292). After inlining, those two ordinary read operations provide no forced ownership of A/B. At the cross-edge each original array is forwarded directly into an explicitly borrowed parameter, without reset/reuse, mutation, constructor storage or a returned array. InferBorrow's annotation override at 287–293 therefore blocks ordinary call-argument ownership heuristics. Its forced self-tail rule at 405–415 applies only to an owned argument in a self-call; it does not create a mutual-TCO guarantee. Element-result temporaries and their cleanup still need inspection; read-only access by itself is not proof that the whole transition is RC-free.

The C emitter adds LEAN_EXPORT and ordinary parameter types at codec-LCNF-EmitC.lean:925–963, not a C noinline attribute. Lean noinline is therefore not a promise that Clang preserves two separately visible bodies. For the future check, resolve the selected native implementations and every transformed cross-edge, rather than stopping at wrappers or interpreting a missing source-named edge as failure. A genuine fused loop can also avoid unbounded calls, but its state/layout and hot-path work must be inspected separately. Ordinary call/return growth, transition state allocation, dynamic apply or post-cross-call cleanup falsifies the intended mechanism.

There are 18 direct parameters: eight USize, two arrays and eight Float32. EmitC's over-closureMaxArgs array-argument convention is conditional on a boxed name (949–961); that is not evidence that the direct unboxed entry has this convention. Any runner must distinguish the boxed wrapper from the selected native recursive implementation. The probe's exact parameter order is text-checked; its actual reduced ABI, typing, termination proof, machine tail jumps, q residency and speed all remain NOT_RUN or UNKNOWN. No claim of profitable BMM behavior follows from this prerequisite.
