# FloatLib 技术规则

执行范围与授权见根 [AGENTS.md](../../../AGENTS.md)。以下是本赛道的技术验收要求；线上政策、冠军与注册额度在正式操作前重新核对。

- 固定官方源、Lean、FloatLib、bench、contract 和 gate 的精确版本。官方目录保持原版；候选只在本赛道 candidates 下修改。
- 完整包只包含 UTF-8 `Kernel.lean`，最多256000字节；仅导入 ContractTensor，在 Submission 定义 add、mul、sum、bmm 和对应四个 *_spec。原 obligation、内核重放、公理审计与逐类 checksum 均须按完整官方 gate 验收。
- 全输入逐位匹配包括 NaN、Inf、次正规数和正负零；sum/bmm 指定逐步舍入顺序。精度容差、实数恒等式或更准确输出不能代替该等价要求。
- 只接受 propext、Classical.choice、Quot.sound；现有引理迁移后重查其完整依赖，不因 leanchecker 成功就忽略额外原生公理。
- 计时遵守官方十二类输入与默认25配对轮。headline为各类跨轮最小值分别求和后的候选／参照比；晋升另要求 ratio≤0.97 与配对中位数 bootstrap 的收益p05>0。按2000次抽样复算时保留精确证据与官方策略版本。
- 报告 ratio、十二类与四函数耗时、完整 gate 状态、精确候选／参照哈希、工具链、CPU、种子、轮次和测量顺序。同源码对照、发现样本、独立新runner确认分开；一个好结果不当作稳定提升。
- 公共 gate、对官方旧参考的比值、对线上冠军的正式结果与链上奖励分列。冠军源码不可得时注明 UNKNOWN，不由旧参考比值推算官方 admission。
- 当前奖励政策为最近三任冠军分赛道预算60/30/10，不是速度榜前三；赛道占验证者权重20%。当前状态从官方API保存原始响应、时间、哈希与快照。政策份额不等于已到账或保证美元收益。
- 每次注册仅提供一次被存入提交的机会；包括拒绝或错误结果也可能消耗。DEFLATE使用检查及注册截止规则须操作前核对；旧额度规则不能直接沿用。
- Linux x86_64官方runner上执行，保留实际CPU与绑核信息。允许源码级等价优化与官方许可属性；编译器、gate、bench、contracts及环境参数不作为候选作弊面修改。
