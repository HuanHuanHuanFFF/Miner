# norm26 的已验收数学改动

精确候选 `79615bd5c5c697d27631b999d7211c41dc5d0c4374cd9604324b417b1ad417d7`
为255514字节。[配方](build_norm26_36.py)把R27已有的商界移植到完整公开36；
不是新的除法原理。CI3原始门禁至axioms通过，见[原始回执](../../evidence/41107618451/download-61071bff514a4286bc113fab65196ffd/public36-norm26/full-gate-verdict.json)。

设D为正分母，r为小于D的余数，s为本路径的左移量。原有界给D<2^36。
将s的守卫从8放到26后，有

`ra=r·2^s < D·2^s ≤ D·2^26 < 2^62`，

所以64位左移仍精确。但仅使用`ra/D≤ra`不足以恢复后续原有位宽界；新增的关键界是

`floor(ra/D) < 2^s ≤ 2^26`。

原有主商部分满足`qq·2^s<2^61`，因此组合商

`qa=qq·2^s+floor(ra/D) < 2^61+2^26 < 2^62`。

这保住了原有偏置合并与最终舍入所需的位宽条件。代码继续使用同一余数、符号处理、
偏置合并和最终舍入；其余十一入口的运行定义未改变。证明中的511字节标点空白压缩
只用于源码上限，完整实际源仍重新通过了原门禁。

CI3两根探索数据共360 paired rows，耗时比公开36为0.9444366337，guard通过；
这只支持该次完整模型约5.56%的改善。按18:15冠军56报告链推算为1.101395倍，
仍未达到冠军；跨配置/环境推算不等于现任源码同机比较。新标准runner确认另由Droot验收。
当前结论和原件绑定见[本方判定](CI3-ROLE-DECISION.json)，历史创建回执中的UNKNOWN不改写。
