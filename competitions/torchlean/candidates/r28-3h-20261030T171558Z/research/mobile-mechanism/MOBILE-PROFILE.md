# Optional baseline Mobile stage-cost discriminator

`profile_mobile53.py`, SHA256**81badda63176a32a8701994ad21eea25e9866d19fb7387ce1f4b5708abb9dd98**, adapts the already-run Root ResNet profile without changing scored binaries, original bench or candidate source. It is ready only if D chooses a later Mobile representation batch; do not mutate the active zero53 CI2 plan or launch an extra CI just for this profile.

API is the existing `run_profile(g,bm,visible,config,control_binary,source_sha,out,global_end)`. Target is exact public53 baseline. Seven exported entries (`ao/ap/aw/ay/Ybl/Ybf/rBnInplace`) produce eight bins: conv_other, pointwise, depthwise, linear, avgpool, maxpool, add_relu, scale_shift. The ao wrapper reads original ConvShape fields4/5 (`kh/kw`) **before** the original function consumes its shape;1×1 goes to pointwise, every other convolution to conv_other. Current benchmark dimensions are small Nat payloads; this classifier is not a general arbitrary-input kernel.

The separate instrumented binary has a240-second total cap and≤20-second individual runs, compares all36 checksums against untouched control across six Mobile cells, and records contract/source/C/binary hashes. Full C remains ephemeral; only own transformation, raw diagnostic lines, commands and derived counters are retained. Constructor field layout follows pinned ContractExact and is hashed in the actual result. Missing symbols or build/runtime problems must remain INCOMPLETE_DIAGNOSTIC_ONLY under the existing parent runner exception handling; no scorer/gate fallback is relaxed.

`mobile-profile-static-test.json` verifies eight unique bins, seven wrappers and one shape dispatcher against synthetic C headers. This is not a real generated-C or native result. Any resulting percentages are exclusive entry times within these profiled calls; kernel output destruction and other whole-model overhead remain outside, and instrumentation can perturb timing. They can guide local-channel versus pointwise proof investment, not establish a whole-model speedup or champion score.
