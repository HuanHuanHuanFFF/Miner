# Single-board FP route and proof byte budget

Decision note, not an implementation or benchmark claim. Current snapshot names MLP champion33; recheck live identity/policy before any result. Current multiplier UNKNOWN.

The user now accepts any TorchLean model board. A candidate may keep all12 correct interfaces while implementing `ExactRuntime.specKernels` for families outside its chosen model. For the MLP model, only dense.linear is executed. Consequently, a full proved FP linear candidate need not append its proof closure to the218KB public12 all-operator source. It can start from specKernels, replace dense.linear with the proved FP version, and retain the spec fields elsewhere. This is a general linear algorithm, not a workload-seed or fixed-shape specialization.

The cleanest fallback is ExactRuntime.dotOf on the original getters, including bias as the final exact product. Its correctness is the specification itself, so it avoids an additional native-word fallback closure. Its cost on misses must be measured; the old cohort had155misses/69600dots but1.23percent of MAC work in rejected calls, so a much slower fallback can still matter. The existing strong12 YaU fallback remains a cost control, not a silently interchangeable implementation.
