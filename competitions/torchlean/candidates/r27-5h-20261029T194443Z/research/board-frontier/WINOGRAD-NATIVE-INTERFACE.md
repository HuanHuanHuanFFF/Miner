# Conditional next native interface

This began as a constraint for a possible next discriminator. After the shared63760B native carrier removed the source-size obstacle, a small complete `WinogradRuntime.lean.inc` and `build_winograd_probe.py` were prepared while D's batch3 ran; neither is compiled. Native execution remains behind the packed-output cost decision or an explicit D/R file decision, with no large matrix-proof investment.

- Keep per-row and per-weight-row min-exponent alignment. Cache each signed magnitude as a Nat payload `magnitude + sign*2^32`, below2^33 when admitted; on the pinned64-bit Lean runtime this can stay an immediate value. Avoid Array Int64/UInt64 boxes and allocating Int in each multiply. Invalid spans keep the strong predecessor's per-output fast fallback.
- Admit a row/column pair only when `maxAbsRow + maxAbsColumn < 2^32`. Decode the payload to a two's-complement UInt64 for addition only. Each cross-sum has actual signed magnitude<2^32; multiply its two unsigned magnitudes and separately carry the product sign. Never sign-extend the low64 product as if it were always signed63.
- Accumulate cross-products in two scalar UInt64 words, then subtract precomputed row and column self-products and append the odd tail. For a deliberately conservative `k<2^30` fast domain, the separate intermediate sums fit signed128; broader k falls back. This needs an actual all-input proof of the signed updates and corrections, not only the scalar ring identity.
- Use the already validated complete-caller bias alignment: `low=min(rowBase+columnBase, biasIndex+149)`, add bias before one terminal rounding, and replay the strong exact dot on a zero total to preserve zero sign. Existing #12/#27 Yc/YaU/Yai are available as read-only strong metadata/fallback interfaces; whole third-party source remains private.
- Do not use a slow original specification call for every ineligible output:26.8%/15.6% of sampled first/second linear outputs miss the factor bound, so such a fallback could overwhelm the proposed arithmetic saving. Reuse row/column metadata and the strong predecessor's corresponding per-output path.

The minimum useful experiment is the same complete Mixer binding as packed evaluation: only the two channel-linear calls change; lexical GEMM and rows1 classifier remain #27. Include cache creation/drop, self-product preparation, cross-products, fallback, output and terminal costs. The observed hypothetical multiplication ratios are0.7213 and0.6460 after all-row/column preparation products and scalar fallback, but actual time is UNKNOWN. A new full candidate must still satisfy256000B and the original12 gate; an auxiliary runtime diagnostic does not establish either.
